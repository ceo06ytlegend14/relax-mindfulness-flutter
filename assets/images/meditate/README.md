# Meditation artwork

The daily-journey and practice thumbnails, plus the small card-backdrop crops, contain artwork from the Meditate reference supplied by the user. No interface text, buttons, or navigation are baked into these assets.

`forest_sunrise.webp` is an AI-generated clean landscape, made using that reference for visual direction. Headings, chips, session information, and buttons are live Flutter widgets. All artwork is bundled locally instead of depending on external image services.

Confirm rights to redistribute the user-supplied reference artwork before a public store release.

The editorial typeface is Cormorant Garamond from Google Fonts. Its SIL Open Font License is bundled at `assets/fonts/editorial/OFL.txt`.
