# Full-screen player artwork

Created with AI image generation on 2026-11-19 using the user's sunrise-lake player concept as visual direction. These are newly generated photographic-style scenes, not crops of the reference interface or photographs of an identified person.

| File | Size | Use |
| --- | --- | --- |
| `lake_dawn.webp` | 768 × 1376 | Edge-to-edge mountain lake at dawn behind the live player. |
| `comfort_art.webp` | 900 × 900 | Meditation silhouette at a lake; rounded cover for non-sleep sessions. |

Generation outputs were resized/compressed locally to WebP. Only the optimized assets are bundled; intermediate PNG masters are not required. Player text, breathing rings, timer, seek slider, transport, chips and completion card are real UI, not baked into either image. Sleep sessions use `../sleep/moonlit_shore.webp` for their cover.

Artwork does not supply narration, music rights, downloads, streaming quality or playback-speed features. Playback continues to use the app's existing calming-audio sources.
