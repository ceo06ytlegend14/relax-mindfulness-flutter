# Moonlit mixer artwork

The moon/forest background and the six rain thumbnails are cropped from the design reference supplied by the user for this redesign. They contain artwork only; all headings, sound cards, buttons, switches, sliders and navigation are real interactive widgets, not a screenshot overlay.

These files are bundled locally so the landing design does not depend on external image services. Confirm permission to redistribute the supplied reference artwork before a public store release.

The MixerSans typeface is Roboto, from the Google Fonts repository. Its SIL Open Font License is bundled at `assets/fonts/mixer/OFL.txt`.
