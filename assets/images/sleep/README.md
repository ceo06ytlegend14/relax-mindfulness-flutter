# Sleep artwork

`moonlit_ocean.webp` and `ocean_journey.webp` are AI-generated clean landscape backgrounds, made using the user-supplied Sleep reference for visual direction. Carousel and continuation thumbnails are artwork-only crops from that reference.

All headings, timer state, progress/level information, buttons, sound toggles, stories, and navigation are real widgets, not screenshot overlays. Artwork is bundled locally, so these screens do not depend on external image services.

Confirm rights to redistribute the user-supplied reference artwork before a public store release. Playback uses the existing AppState audio engine; this artwork does not add individual story narrations or a download service.
