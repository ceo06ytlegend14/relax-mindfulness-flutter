# Sleep artwork

The following photographic-style assets were generated with AI using the user's supplied Sleep/player concepts for visual direction, then optimized locally to WebP. They contain scenery, not screenshot interface elements.

| `rain_window.webp` | 600 × 600 | Newly generated rain-on-window scene; Heavy Rain playlist cover. |

## Retained reference crops

`continue_listening.webp`, `heavy_rain.webp`, `night_forest.webp`, `ocean_waves.webp`, and `thunderstorm.webp` are artwork-only crops from the earlier user-supplied Sleep reference. Some remain in catalog/story or track-cover uses, even where the latest playlist has a newer generated cover. **Confirm redistribution rights to those reference crops before a public release.**

All headings, timer state, progress/level information, buttons, sound toggles, stories, and navigation are real widgets, not screenshot overlays. Artwork is bundled locally, so these screens do not depend on external image services.

Playback uses the existing AppState audio engine. These visuals do not add individual story narration or a download service. See `../player/README.md` for the full-screen player's new sunrise-lake artwork.
